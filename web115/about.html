Welcome to my About page. This site is basically where I drop all my WEB115 course assignments, keep track of my progress, and put what I am learning into practice as I work through the semester.

To get everything set up and make sure the pages actually pass the validator, I use a few standard tools and plan on putting together a few different sites for this class:

  • VS Code: The text editor I use to write and edit my code.
  • Emmet: A shortcut tool built into the editor to write HTML and CSS way faster.
  • GitHub: Where I store my project files and host everything live on the web.
  • Accumulus: The cloud script in the header that helps track site scripts.
  • Vicunadator: The validator tool that checks my pages against course rules before I turn them in.
  • Personal Site: My own independent portfolio site outside of class work.
  • Course Site: This exact workspace for WEB115 holding all my milestones and contracts.
  • Design Site: A separate layout project focused on design styles and visuals.

When I am not coding or working on web development projects, I usually chill and play games to unwind and recharge.
